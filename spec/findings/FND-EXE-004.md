## Interpretation

The game's own code is the 464 functions of the first range; everything after
`0x0047862F` is library code the spec treats as out of scope, except where a
rule depends on a runtime function's behaviour (the random number generator
`_rand`, RULE-RNG-001, and the float-to-integer conversion `__ftol`). The table
is the fixed denominator for "every function of the game" and gives the full
address range of any function the spec cites by entry address alone: a
function's range is its entry through its last byte in this table.

## Alternatives

Auto-analysis could split one source function into two or merge a function
into the one before it. The 309 unassigned bytes are all short gaps between
functions, so no game code is left out, but a boundary could still be placed
wrongly where a function falls through into the next. None was seen in the
functions the spec describes.

## How to reproduce

Import `Chaos Overlords.exe` into Ghidra 12.1.3 with the default analysers,
then list the function manager's functions with their entry points, body
maximum addresses, body sizes and calling functions. The import thunks are the
functions whose names are imported API names; the first runtime function is
the one Ghidra's function ID names `_memcpy`.
