## Use

Says that the system forms a caret by inverting the pixels of a rectangle
given by its position, width and height, inverting every pixel for a solid
caret and every other pixel for a gray one, and that a shown caret flashes. The
blink time, the time to invert the caret, is a setting the user makes in the
Control Panel, and the flash time is twice the blink time. It describes the
caret of the player name dialog's edit control (SCR-SETUP-003).

## Known errors

The page gives neither the default blink time nor the size of the caret an
edit control creates.
