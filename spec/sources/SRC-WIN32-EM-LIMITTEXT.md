## Use

Says that before `EM_LIMITTEXT` is sent, the default limit on the text a user
can enter in an edit control is 32,767 characters. The game never sends it to
the player name dialog's control (FND-UI-068), so that is the control's limit.

## Known errors

The page documents the current Windows edit control and describes no run of
the game.
