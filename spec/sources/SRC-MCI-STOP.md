## Use

Defines the CD distinction between stop and pause: stop resets position within the current track to zero, while pause preserves it. FND-AUDIO-007 records the executable calling these commands.

## Known errors

The page documents the legacy platform API, not a run of the game or a GOG
compatibility wrapper. It does not establish any device-specific error behavior.
