## Use

Defines the default start and end positions when MCI_FROM and MCI_TO are omitted. It supplies the platform meaning of the positionless request in FND-AUDIO-007.

## Known errors

The page documents the legacy platform API, not a run of the game or a GOG
compatibility wrapper. It does not establish any device-specific error behavior.
